# Project 4: Hash Table

A Python implementation of a hash table data structure built from scratch.

## What it does
- Hashes string keys using Unicode character values
- Stores key-value pairs in a nested dictionary structure
- Handles hash collisions by storing multiple pairs under the same hash
- Supports add, remove, and lookup operations

## Concepts demonstrated
- Object-oriented programming
- Hash functions and collision handling
- Dictionary manipulation
- Unicode character encoding with `ord()`
