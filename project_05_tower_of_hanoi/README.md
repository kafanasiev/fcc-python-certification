# Project 5: Tower of Hanoi

A Python implementation of the Tower of Hanoi puzzle solver using recursion.

## What it does
- Solves the Tower of Hanoi puzzle for any number of disks
- Returns all moves as a formatted string showing rod states at each step
- Solves in the optimal 2ⁿ - 1 moves

## Concepts demonstrated
- Recursive algorithms
- Nested functions
- List manipulation
- String formatting and joining
