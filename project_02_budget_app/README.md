# Project 2: Budget App

A Python program that tracks spending across budget categories and visualises relative spending as a bar chart.

## What it does

* Creates budget categories with a ledger of transactions
* Supports deposit, withdrawal, transfer, and balance operations
* Prevents overdrafts via fund checking
* Generates a vertical bar chart showing the percentage spent per category

## Concepts demonstrated

* Object-oriented programming (classes, instance methods)
* List manipulation and dictionary handling
* String formatting (alignment, padding, centering)
* Data aggregation and percentage calculation
