# Project 3: Polygon Area Calculator

A Python program that calculates area, perimeter, and diagonal of rectangles and squares using object-oriented programming.

## What it does

* Creates Rectangle and Square objects with geometric calculations
* Generates ASCII art picture of the shape
* Calculates how many times one shape fits inside another

## Concepts demonstrated

* Object-oriented programming (inheritance, method overriding)
* Class and instance attributes
* String representation with `\_\_str\_\_`
